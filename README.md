# Music Download - Web Proxy (重构)

将仓库改为一个小型前端 + 后端代理，用于在网站上下载远程音乐/文件。

## 运行

1. 克隆仓库并切换到项目目录
2. 安装依赖：
   npm install
3. 启动服务：
   npm start
4. 在浏览器打开：
   http://localhost:3000

## 使用说明

- 在输入框粘贴远程文件的直链（例如 .mp3/.m4a/.flac/其他文件直链），点击“下载”。
- 后端会把远程文件流转发给浏览器并设置下载文件名。
- 如果目标资源需要 Cookie/认证或对 User-Agent 有严格限制，可能无法下载。

## 部署建议

- 上线前请添加鉴权/域名白名单/速率限制等安全措施，避免被滥用。
- 可部署在支持 Node.js 的主机（例如 Heroku/DigitalOcean 等），但注意 Serverless 对长连接/大文件的限制。
